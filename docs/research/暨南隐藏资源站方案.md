# 「暨南大学隐藏资源导航站」方案调研与落地建议

> 背景：在"卓越杯"B 应用实践赛道下，你提出做一个**暨南大学隐藏资源导航网站**，参考数字生命卡兹克（卡兹克）的 AI 热点站 AIHOT。
> 本文目标：① 澄清 AIHOT 到底是什么、能不能抄；② 把"隐藏资源站"的正确产品形态定下来；③ 给出内容框架、AI 层设计、三条技术路线、以及与比赛评审的契合点。
> 时间约束：初赛 10-08 截止，仅约 16 天 → 所有路线按"可快速落地"筛选。

---

## 一、参考对象 AIHOT 到底是什么（先厘清，避免误判）

**AIHOT = aihot.virxact.com**，卡兹克（公众号"数字生命卡兹克"）做的 AI 行业热点聚合监控平台，核心形态：

- **168 个精选信源**（X / 博客 / RSS / arXiv / 公众号）→ DeepSeek 预筛 → **AI 打 0–100 分** → 人工反馈闭环（评分策略迭代了 11 版）
- 页面板块：**精选**（带"推荐理由"）、全部 AI 动态、AI 日报、低粉爆文、信源分级地图（T1/T1.5/T2）、信源提报、收藏
- 分类页签：模型 / 产品 / 行业 / 论文 / 技巧；还有"当前热点"（几个信源在报，判断真热还是自嗨）
- 接入：网页 / **Agent Skill** / **RSS** / **REST API**，匿名免 token，个人非商业免费
- 战绩：公开首日 UV 10 万+、PV 60 万+

**⚠️ 开源真相（关键）**：
- AIHOT **网站本体代码未开源**，是卡兹克公司（北京虚实空际文化科技）的专有产品。
- **开源的只有**：① `aihot` Skill（github.com/KKKKhazix/khazix-skills，可 fork 改造成你的 Agent 工作流）；② 公开 API（个人非商业免费，商业/镜像转售需书面授权）。
- **真正能整站 fork 的同类开源项目**：**ai-news-radar**（github.com/LearnPrompt/ai-news-radar，MIT 协议，Python 抓取 + JS 前端 + GitHub Actions 定时 + GitHub Pages 托管，可配自己的信源）。

**结论**：别想着"扒 AIHOT 代码改一改"——抄不到。但可以**借鉴它的产品范式 + 用它的公开 API/Skill 做灵感**，技术底座改 fork ai-news-radar 或自建目录站。

## 二、概念纠偏：你的站不该是"新闻聚合器"，而是"策展式目录 + AI 问答"

AIHOT 是**自动爬取的实时资讯流**；"暨南隐藏资源"是**半静态、靠人维护的校园资源目录**（类似学校百事通）。两者架构不同：

- **架构上更该参考的"校园导航站"**（已开源、可借鉴结构）：
  - **ut01**（德州大学奥斯汀，github.com/LEAD-UTexas/ut01.github.io）：学生导航枢纽，分类=关键门户 / 学术事务 / 财务 / 校园生活 / 技术服务 / 国际学生；特点=快捷访问、可设主页、移动响应、学生维护。
  - **bit-guide 北理生活指南**（github.com/yht0511/bit-guide）：MkDocs 静态站，板块=校园生活 / 活动社团 / 学习竞赛 / 附录，支持公众贡献 Markdown。
  - **college_student_self-rescue_guide_website**（大学生自救指南）：全栈 Web，功能=浏览/搜索/筛选/收藏/评分/评论 + 后台 RBAC，Vercel 部署。
  - **Softr Student Portal**（无代码模板）、**ncxweb.cn 校园网页作品集**（迎新/学生会/社团/长期信息 四类方向）。

- **AIHOT 真正值得"借"的产品范式**（迁移到你这）：
  1. **每条资源带"推荐理由"**（谁该用、为什么值）——比干巴巴的链接更打动人
  2. **清晰分类页签 + 搜索**——信息再多也能 3 秒找到
  3. **"当前热点 / 本校新生必看"置顶区**——把最该知道的放最前
  4. **Agent 接入思路**——做一层"用大白话问，AI 帮你挑资源"的智能体（这正是你"AI+X"的差异化点）

## 三、内容框架：暨南隐藏资源该收录哪些类目

（综合多所高校"隐藏福利"盘点，按"新生/日常/省钱/成长"四维组织）

| 类目 | 具体资源示例 |
|---|---|
| **学术数据库** | 知网 / 万方 / 维普 / IEEE / SCI / 外文文献库全校免费访问（校外一篇几十元）；图书馆电子书、研讨室、免费打印 |
| **正版软件** | Office / Windows / Adobe 全家桶 / MATLAB / AutoCAD 教育版免费或低价；编程工具、建模软件、思维导图 |
| **教育邮箱权益** | 用 edu 邮箱领免费/半价软件、付费域名；微软 1TB OneDrive；UNiDAYS、GitHub Student Pack |
| **学习平台** | 中国大学 MOOC 名校课、校内实训系统、四六级/雅思托福公益讲座、外语口语小班 |
| **出行优惠** | 火车/高铁学生票（每学年 4 次，二等座 7.5 折）；共享单车学生月卡；12306 资质核验 |
| **景区/休闲** | 全国国有景区/博物馆学生半价或免费（故宫 20 元、黄山泰山莫高窟半价）；电影学生票；海马体证件照 88 折 |
| **餐饮/数码** | 海底捞学生折扣（6.9 折时段）、美团/饿了么学生红包；苹果/华为/联想教育优惠；京东搜"学生555"领券 |
| **影音/工具会员** | WPS/夸克/百度网盘学生价；爱奇艺/腾讯视频/优酷学生年卡；QQ 音乐绿钻首月 5 元 |
| **校内服务导航** | 饭卡余额/充值、报修、图书馆、校医院报销、心理咨询（免费一对一）、职业规划/简历修改/模拟面试 |
| **成长/人脉红利** | 大佬讲座/公开课、保研夏令营、海内外交换访学、跨专业辅修/二学位、双创孵化器（免费场地+免息贷款）、校友内推、企业校招绿色通道 |

> 落地提示：暨南有**珠海/深圳/广州多校区 + 侨校 + 120 周年校庆**特性，可加"校庆专属福利 / 侨生专项 / 各校区差异化服务"类目，做出别人抄不走的差异化。

## 四、AI 层设计（你的"AI+X"差异化，直接对应比赛主题）

把 AIHOT 的"推荐理由 + 分类 + Agent 接入"思路，落成一个**低代码智能体**：

- **做法**：把上面的"隐藏资源目录"作为知识库（RAG），用 **Coze / 百度智能体 / Dify** 搭一个"暨南资源小助手"。
- **交互**：学生用大白话问 ——"我是新生想省钱""保研有哪些隐藏渠道""深圳校区打印在哪"—— 智能体从目录里挑最相关几条，并附"推荐理由"。
- **为什么好**：① 零/低代码、16 天可交付；② 天然是"AI 应用"，契合"智创未来·人人皆可 AI"；③ 呼应 AIHOT 的 Agent 接入范式，但内容是你的原创。
- **进阶（有技术队友）**：前端目录站 + 后端接大模型 API，做站内语义搜索（仿 AIHOT 的"按主题/关键词搜"）。

## 五、三条技术路线（按你的代码能力选）

| 路线 | 适合 | 做法 | 交付物 | 难度 |
|---|---|---|---|---|
| **A·低代码智能体 + 轻目录** | 零基础（最推荐） | Coze/百度智能体做问答助手（目录作知识库）+ 一份 Notion/飞书多维表格做目录 + 简单落地页 | 可对话 Demo + 目录页 + 录屏 | ★ |
| **B·静态目录站** | 会一点 | fork/仿 bit-guide（MkDocs）或 GitHub Pages + Markdown，部署到 Vercel；可选接智能体 | 可访问网址 + 搜索/分类 + 录屏 | ★★ |
| **C·全栈 Web 应用** | 有技术队友 | fork college_student_self-rescue_guide_website（Next.js + Vercel），加搜索/收藏/评分/后台；或 fork ai-news-radar 改造成目录 | 完整 Web 应用 + 源码仓库 | ★★★ |

> 无论哪条，**B 赛道初赛都要交**：作品说明书（PDF≤10 页）+ 可运行 Demo（录屏或链接）。路线 A/B 在 16 天内完全可行。

## 六、与比赛评审的契合点（为什么这个选题能打）

- **B 赛道"场景落地价值"占 40%（权重最高）**：新生/学生"不知道学校有哪些隐藏福利"是真实痛点，且人人都遇得到 → 易打动管理学院评委。
- **"AI+X"主题完美契合**：目录（X=校园服务）+ AI 问答层，正是跨学科融合范例。
- **可交互 > PPT**：做出能"输入问题→输出资源"的 Demo，比方案书竞争力强得多。
- **跨学科组队加分**：拉一个会前端的同学，直接 A→C 升级，产品完整度拉满。
- **原创性安全**：内容是暨南专属原创，不碰 AIHOT 专有代码；借鉴"产品范式"不侵权（思想不版权）。

---

## 七、版权 / 原创性红线（务必避开）

1. **不要复制 AIHOT 网站代码**（专有，未开源）；可 fork 的是 `aihot` Skill 与 ai-news-radar（MIT）。
2. **AIHOT 公开 API / Skill**：个人非商业免费可用；若做"镜像/转售"需卡兹克书面授权——比赛作品属非商业，一般 OK，但别拿它当自己后端硬依赖（他随时可关，且只存 7 天）。
3. **校园导航站（ut01 / bit-guide）**：GitHub 开源，可参考结构；你的内容是暨南专属，本就独立。
4. **AI 生成内容须标注**（章程第七条）；引用数据注明出处。

## 八、下一步建议

最稳路径：**路线 A**——用 Coze/百度智能体搭"暨南资源小助手"（目录作知识库），配一份飞书/Notion 目录页，3–5 天出 Demo，剩下时间打磨说明书写法 + 录屏。若想更"像网站"，升级到**路线 B**（MkDocs 静态站，半天部署）。

需要的话，我可以直接帮你出一份 **Coze/百度智能体搭建"暨南资源小助手"的分步实操清单**（含知识库字段设计、Prompt 模板、目录页表格结构），或一份 **MkDocs 静态站 30 分钟上手指南**。
