# 「卓越杯」方向深度调研：集合全校资源的校园智囊图

> 调研日期：2026-09-23 | 模式：思维发散→收缩（跳出就业框）| 专家扫描：当前环境无真实可用专家，主 Agent 亲执行
> 约束回顾：B 应用实践赛道（要可运行 Demo＋说明书）、管理学院、16 天、低代码、"正常服务没有的贴身感＋让人眼前一亮"

## 一句话结论

**别再做单点工具，做一个"集合全校资源"的平台级想象——「暨囊·暨南校园资源智囊图」**：把**人 / 作品 / 想法 / 非官方情报 / 官方资源**全部众包聚合，用 AI 做"匹配调度＋主动惊喜推送"，核心是**把同学当可用资源**（校园版时间银行＋人才图谱），并让每个使用者**顺手贡献数据**（众包训练数据＋表彰）。

这不是空想——你列的每一块，都有真实高校/产品先例撑腰（见下表）。关键是把它**收敛成一个 16 天低代码能跑的 MVP**。

## 二、收敛后的旗舰方向：「暨囊·校园资源智囊图」

### 形态（一个 workflow，不膨胀）
学生用大白话问（或填表登记）→ AI 从"资源图谱"里捞出**最相关几条**＋**主动附一个"你绝不知道但会用上"的惊喜资源**。

**资源图谱 = 飞书多维表格**，字段示例：
- 资源类型（人 / 作品 / 想法 / 情报 / 官方）
- 提供者（昵称，学号**脱敏**）
- 我能提供 / 我需要（时间银行双向）
- 标签（技能·专业·场景）
- 时间币定价（1 小时＝1 币，可兑换他人服务）
- 描述 / 提交时间

**AI 调度中枢 = Coze 智能体**，用"飞书多维表格"插件做查询＋大模型匹配＋主动惊喜推送。

### Demo 脚本（让人眼前一亮）
> 学生："我想学 Python 但没钱报班，还想找实习"
> 暨囊回：① **计院王同学**可 1 对 1 辅导（收 2 时间币，你用帮新生指路赚回）；
> ② 上周**李同学**发的《AI 学习笔记》作品正好入门；
> ③ 情报：**某司内推通道今晚 24 点截止**（你不知道的）；
> ④ 暨南隐藏福利：图书馆免费数据库账号。
> ——"你没问的，我先给你了"＝海底捞式超预期，但落在扎实资源上。

### 为什么同时命中你四个硬约束
- **正常服务绝对没有**：学校从发"人才匹配/技能交换/非官方情报流转"工具 → 真空白（现有网站只有通知/招聘，无 P2P 资源调度）
- **贴身感＋哇点**：主动推送"你不知道的身边资源"＝反向个性化惊喜（前轮论证的全校级空白）
- **16 天低代码可交付**：Coze＋飞书多维表格，**零代码**（一泽教程证实"自动整理入库＋智能推荐"两天可做）
- **管理学院评委秒懂**：可套"共享经济 / 时间银行 / 众包 / 长尾理论 / 双边市场"——全是商科语言

## 三、为什么能拿奖（对照评委铁律）

多校智能体大赛评审口径高度一致（北航/西财/大连理工/常州）：
1. **扎根真实场景、不搞通用大模型套壳**（北航明文："所有成果均扎根真实场景"）→ 你的"校园时间银行＋情报流转"是真痛点
2. **能落地、可复用、有证据链** → 用 ≥10 名同学真实登记做冷启动数据＋试用反馈
3. **师生共创 / 众包**反而加分 → 清华"清小搭"模式已被官方树为标杆，你"让学生共建图谱"正中下怀
4. **场景越窄越狠** → 砍掉"作品/想法/情报"里花哨的部分，MVP 只保"人（技能交换）＋情报（合规非官方）"两条线

**商科护城河**：时间银行/双边市场/众包激励设计是管理学科本色，评委（本院老师）天然共鸣，且你能写进说明书当"理论创新性"。

## 四、16 天低代码 MVP 架构（已验证可行）

```
学生端（Coze Web 分享链接 / 公众号菜单）
   │
   ▼
Coze 智能体（人格：暨囊管家）
   ├─ 工作流1「登记」：填表 → 写入飞书多维表格（add_records）
   ├─ 工作流2「匹配」：搜表（search_records）→ 大模型挑最相关 → 主动附惊喜
   └─ 工作流3「推送」：定时/触发 → 模板消息推"本周新资源"
   │
   ▼
飞书多维表格 = 资源图谱库（人/作品/想法/情报/官方）
   │
   ▼
知识库补充：暨南官方资源（图书馆/讲座/校庆/侨校）+ 你就业办可提供的真实数据
```

**真实参照**：飞书官方"Coze＋飞书多维表格"教程（一泽）已跑通"自动整理入库＋智能推荐"，零代码、含 `add_records`/`search_records` 插件写法；语雀"选题自动化系统"证明多维表格＋扣子字段捷径可驱动全流程。**你不需要写一行代码**。

排期（对照 10/8 初赛）：
- D1–2：飞书多维表格建库＋字段设计＋征集首批同学登记（冷启动 10–20 条）
- D3–8：Coze 搭「暨囊」bot（3 个工作流）＋人格 Prompt
- D9：发 Web SDK 拿分享链接 = 比赛主 Demo
- D10–12：绑就业办公众号菜单＋配"每周新资源"推送
- D13–15：写说明书（含理论框架＋冷启动数据＋试用反馈）＋录 2 分钟 Demo
- D16：打磨答辩（30 秒讲清"谁/什么麻烦/怎么解决"）

## 五、⚠️ 必须守住的红线（这是负责任的研究结论，不是泼冷水）

你方向里最"大胆"的两块——**收集人、收集小道消息**——正好也是**合规/伦理高风险区**，评委（及学校）会重点挑刺。必须这样落地：

1. **"小道消息"必须重定义为"合规非官方情报"**：内推/二手/拼车/选课评价/老师风格/活动——**绝不碰**谣言、八卦、对个人的负面评判。纯吃瓜/爆料聚合＝评委红牌＋校方合规风险（参照北大树洞被校方严管、内容审查扩大）。**建议改名"暨南情报站"，只收"有用信息"**。
2. **"收集人"=技能/资源登记，不收集敏感信息**：学号脱敏、不存手机号/证件号；借鉴北大树洞"加密数据库＋密钥分离"与西北农林"严格数据加密和隐私保护"。明确《服务协议》+《管理规范》。
3. **"训练数据"用清华表彰模式，别白嫖**：每个贡献者在图谱里**署名＋致谢＋贡献榜**，让用户有荣誉感（清华"清小搭"因此被官方表彰）。这反而成"人机共创/众包治理"的亮点。
4. **合规底线**：参照《生成式人工智能服务管理暂行办法》——清华/南开都明确"知识库过滤风险内容、提问风险分级"。AI 输出标注"AI 辅助，以官方/当事人核实为准"，不做裁决者。
5. **你作为就业办的独特作弊码（别人抄不走）**：① 官方公信力（学生敢把真实资源托付给"学校背景"的平台）；② 可接 scdc 真实数据做"官方资源"层；③ **真人兜底权**（疑似诈骗/危机一键转老师，商业产品无此权限）。

## 六、"大胆"但稳妥的收口建议

- **MVP 只做两条线**：「人（技能交换/时间银行）」＋「合规情报（非官方有用信息）」。作品/想法作为"资源类型"字段先预留，不单独开发。
- **"主动惊喜推送"是哇点担当**：每次对话结尾 AI 必送 1 条"你不知道的身边资源"——把海底捞超预期做成产品哲学，功能不膨胀却记忆点强。
- **众包即训练数据即护城河**：同学每登记/每条反馈都沉淀进图谱，越用越准——这是你相对"官方自上而下系统"的最大优势（自下而上、活数据）。

## 七、与前面几轮的关系（避免来回横跳）

- ✅ 吸收"暨南惊喜盲盒"的**主动惊喜推送**（哇点）
- ✅ 吸收"就业安检员"的**真人兜底/责任边界**（合规亮点）
- ❌ 放弃"抓官网做 AIHOT"（登录墙技术风险，降级为可选数据补给）
- ❌ 放弃纯"陪伴舱"（demo 显不出差异化）
- 🔄 本方向把"人"显式当第一类资源，比前面任何一个都更大胆、也更贴你"集合全校资源"的指令
