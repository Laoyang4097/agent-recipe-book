# 「就业版海底捞」交付路径决策：网站 / 小程序 / 公众号 怎么选

> 背景：卓越杯 B 赛道（应用实践赛），需可运行 Demo，初赛 10/8 截止（剩约 16 天）。你是就业办，作品要"让人眼前一亮"且能真落地。

## 一、核心结论（先拍板）

**用 Coze（扣子）低代码搭一个智能体，一次构建、多端发布：**
1. **Web SDK（H5 网页聊天）** → 拿"分享链接"给评委，**免登录、免安装、点开即聊**，比赛 Demo 最友好。
2. **微信公众号**（你已有的就业办公众号）→ 直接触达真实学生，且能做**模板消息主动推送**，实现"海底捞式预判关怀"。
3. **微信小程序**（可选，排期靠后）→ 做"服务通知"主动推送 + 沉浸体验（简历舱/面试舱式），但需审核，对 10/8 有风险。

> 一句话：**H5 负责比赛惊艳第一眼，公众号负责真实落地与主动关怀，小程序是决赛后的升级项。**

## 二、为什么不是"纯网站"或"纯小程序"二选一

### 网站（传统官网）的硬伤
- 学生**不会主动访问一个 URL**；官网适合"展示/SEO/信任背书"，不适合"日常陪伴/主动触达"。
- **纯网站做不出"预判式关怀"**：你没法主动戳学生"秋招倒计时了""被拒了来聊聊"。主动触达只有微信生态（模板消息/服务通知）能做到。
- 但注意：**Coze 的 Web SDK 生成的 H5 聊天页 ≠ 传统官网**。它轻量、免登录、可分享，是比赛演示利器——我们把它当"Demo 外壳"用，不当"主阵地"。

### 小程序很强但要排期
- 能做"服务通知"主动推送 + 沉浸体验，**最贴近"贴身服务"**。
- 但门槛：需**企业/事业单位主体**（大学符合 ✅）、需**算法备案 + 微信审核**（深度合成-AI 问答类目，约 1–2 周），且**一个 bot 只能绑一个小程序**。
- 风险：10/8 前赶审核太紧。**建议比赛先用 H5+公众号，小程序作为"决赛后真落地"升级项**，现在可先注册主体占位。

### 公众号是最稳的"真实落地"入口
- 西南科大"小信芯"就是**直接挂在公众号菜单**，无独立 App，学生零门槛进入。
- 公众号（尤其服务号）支持**模板消息**，你的"被拒急救 / 秋招倒计时戳你 / 求职战报"等超预期动作靠它实现。
- 你作为就业办，**大概率已运营"暨南大学就业"类公众号**，直接复用粉丝，零获客成本。

## 三、渠道能力对照表（基于 Coze 官方文档实测）

| 渠道 | 免登录体验 | 主动推送(预判关怀) | 比赛 Demo 友好度 | 真实学生触达 | 上线周期 | 适合角色 |
|---|---|---|---|---|---|---|
| **Web SDK (H5 链接)** | ✅ 分享链接即开 | ❌ 不能主动推 | ⭐⭐⭐ 最友好 | 中（需分发链接） | 即时 | 比赛 Demo + 分享 |
| **微信公众号** | ✅ 菜单即进 | ✅ 模板消息 | ⭐⭐（评委需扫码/搜号） | ⭐⭐⭐ 最强 | 快（绑菜单即可） | 真实落地主阵地 |
| **微信小程序** | ✅ 扫码即开 | ✅ 服务通知 | ⭐（需体验码/审核） | ⭐⭐⭐ 强 | 1–2 周(审核) | 决赛后升级 |
| 传统自建网站 | ⚠️ 需记网址 | ❌ | ⭐（需部署/域名） | 弱 | 中 | 品牌展示(非必需) |

> 百度智能体（千帆 AppBuilder）同样支持 网页版+公众号+小程序+网站嵌入，能力对等，可作为备选平台。

## 四、真实高校案例印证（全部走微信生态）

- **西南科大「小信芯」**：公众号"学职引航直通车"菜单入口，无独立 App；非工作时间咨询占 **52%**，累计近千人次。
- **扬州大学「扬大'职'升机」**：微信小程序 + 数智服务平台双载体。
- **渤海大学**：公众号 + 就业信息网 + 网页（aizmx.jiuyeqiao.cn）三端。
- **常州「AI 求职管家」**："常州人社"公众号 + "就在江苏"平台小程序。
- **滇西应用技术大学**：AI 模拟面试小程序（扫码绑定学号）。

> 共同点：**没有一所学校用"纯网站"做主入口**，全部沉淀在微信生态。你的方向完全正确。

## 五、"让人眼前一亮"的超预期动作，靠哪个渠道落地？

| 海底捞式动作 | 实现渠道 | 说明 |
|---|---|---|
| 秋招倒计时主动戳你 | 公众号模板消息 / 小程序服务通知 | 网页做不到主动触达 |
| 被拒急救室（先共情再给下一步） | 对话内（全渠道） | 核心人格，H5 也能演示 |
| 隐藏机会雷达（推你不知道的岗） | 对话内 + 公众号推送 | 主动推送增强"被惦记感" |
| 求职战报（offer 到手出庆祝卡） | H5 生成图片 / 公众号模板消息 | 可截图发朋友圈=传播点 |
| 安静/话痨模式（i 人友好） | 对话设置（全渠道） | 分寸感，差异化 |

> **关键判断**：让人"哇"的瞬间（主动关怀、战报、被惦记感）最终要靠**公众号/小程序**落地；H5 负责让评委**第一眼就哇**。

## 六、落地步骤（16 天排期建议）

1. **Day 1–2**：确认就业办是否有"暨南大学就业"公众号及管理员权限（服务号优先，模板消息更强）；注册 Coze 工作空间。
2. **Day 3–8**：在 Coze 搭「暨小捞」bot（人设 Prompt + 知识库：侨生专项/多校区/百年商科/真实去向）。*我可出搭建清单。*
3. **Day 9**：发 Web SDK → 拿"公开分享链接" → 这就是比赛 Demo 主入口；顺手做个简单落地页包一层增加仪式感。
4. **Day 10–12**：绑公众号菜单 → 真学生可用；配置模板消息（秋招倒计时/战报）。
5. **Day 13–15**：录屏、写项目说明书、准备路演。
6. **（决赛后）**：注册企业主体小程序并提交审核，升级"服务通知 + 沉浸舱"体验。

## 七、风险与红线

- ⚠️ **小程序审核 + 算法备案**对 10/8 太紧，别把它当比赛必交项，当升级项。
- ⚠️ **订阅号**模板消息能力弱于**服务号**；确认就业办用的是哪个，必要时申请服务号。
- ⚠️ 个人主体小程序**不支持** AI 问答类目——但大学是事业单位主体，符合 ✅。
- ⚠️ 数据隐私：学生简历/焦虑对话属敏感信息，知识库与日志需脱敏，符合学校数据规范。
- ⚠️ "防 AI 依赖 / 真人兜底"做成设计原则（AI 识别严重焦虑→一键转真实就业老师），既是合规也是亮点。

## 八、给你的一句话建议

**比赛交 H5 链接（惊艳），真实用公众号（触达+主动关怀），小程序留作决赛后升级。** 一个 Coze bot 全包，零代码、16 天可交付、且别人抄不走（你有就业办本体数据与公信力）。
