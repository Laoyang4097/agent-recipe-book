# 暨南大学就业官网（scdc.jnu.edu.cn）资讯结构分析 & 类 AIHOT 热点抓取方案

> 目标：像卡兹克 AIHOT 那样，把暨南就业官网的资讯"抓取→提炼热点"，喂给你的「暨小捞」就业陪伴智能体。
> 分析日期：2026-09-22。已用 WebFetch 实测首页、5 个栏目列表、分页、详情页。

---

## 一、网站基础画像

- **站名**：暨南大学就业信息服务平台（SCDC = Student Career Development Center）。
- **建站形态**：典型高校就业 CMS（类 91job/侨校就业系统），栏目用 `tag` 参数路由，**无 sitemap.xml、无 RSS、无公开 API、无公开搜索/排行榜**。
- **外链源**：国聘 iguopin.com、国家大学生就业服务平台 tyut.ncss.cn（可作额外"热点源"）。
- **子应用**：简历优化实验室 `careerLab/view/type/resume`；三套登录（学生/单位/教师）。

### URL 规律（实测确认）
| 类型 | 格式 | 示例 |
|---|---|---|
| 首页 | `/` | `https://scdc.jnu.edu.cn/` |
| 栏目列表 | `/news/index/tag/{tag}` | `/news/index/tag/xwkd` |
| 列表分页 | `/news/index/tag/{tag}?page=N` | `?page=2` 生效，每页约 16–20 条，时间倒序 |
| 文章详情 | `/news/view/aid/{id}/tag/{tag}` | `/news/view/aid/676633/tag/xwkd` |
| 图片附件 | `/attachment/jnu/ueditor/images/{YYYYMMDD}/{时间戳}.png` | 见详情页 |
| 登录 | `/user/login`(学生) `/vip/user/login`(单位) `/default/ulogin`(教师) | — |

- **文章 ID 为自增整数**：677008(2026-09) → 665357(2024-12)，可据此估算发文量与时间线。

## 二、栏目可抓取性矩阵（核心结论）

| 栏目(tag) | 内容性质 | 公开可抓？ | 对"就业热点"价值 | 备注 |
|---|---|---|---|---|
| **新闻速递 xwkd** | 宣讲会/双选会/竞赛/校友/校企/政策动态 | ✅ **完全公开** | ⭐⭐⭐ 最高 | **主数据源**，频次高、信息密 |
| **活动报名 zykc** | 训练营/课程开课名单 | ✅ 公开 | ⭐⭐ 中 | 内容稀疏（常仅 1 条） |
| **使用指南 fwzn** | 学生/单位服务指南 | ✅ 公开 | ⭐ 低 | 仅 3 篇，静态 |
| **通知公告 tzgg** | 官方通知/申报/表彰/基层就业 | ❌ **CAS 登录** | ⭐⭐⭐ 最高(学生最关心) | 列表+详情均跳 `icas.jnu.edu.cn` 登录 |
| **校内公示 xngs** | 获奖/拟录用公示 | ❌ **CAS 登录** | ⭐⭐ 中 | 同样跳 CAS |

> **关键判断**：最值钱的"通知公告/校内公示"是登录可见；而"新闻速递"完全公开且信息密度最高，是**无需登录就能抓热点的主力源**。作为就业办，你可用**教师登录态**抓 tzgg/xngs，这是外部人做不到的护城河。

### 隐藏栏目（不在公开导航）
招聘信息 / 宣讲会 / 双选会 / 职位 等"就业核心"模块**未出现在公开导航**，全部在"学生登录"后的就业系统内。要抓这些需学生/教师账号会话或厂商 API。

## 三、文章数据结构

### 列表页字段
- 标题、发布日期、链接（`aid`+`tag`）、无摘要、无阅读量标记、无置顶/重要标记。

### 详情页字段（实测 xwkd 一篇）
- **标题**（H1）
- **发布时间**：格式 `2026年02月01日21:58`
- **来源**：`学生就业指导中心`
- **正文**：富文本 + 图片（ueditor 图床）
- **阅读量 / 点赞 / 热度数字**：❌ 未发现
- **结构化数据**：❌ 无 JSON-LD、无 meta 隐藏字段、无"上一篇/下一篇"
- **附件下载**：详情页以图片内嵌为主，未见独立附件链接规律

> **推论**：站内**没有原生"热度"指标**。热点不能靠浏览数排序，必须用 AI 从【标题+正文+发布时间+主题聚类】中**推导**热度——这正是 AIHOT 的打法（DeepSeek 预筛 + 0–100 评分）。

## 四、技术抓取可行性

| 能力 | 现状 | 应对 |
|---|---|---|
| 列表拉取 | ✅ `?page=N` 可翻页 | 定时轮询每栏目前 N 页 |
| 详情拉取 | ✅ xwkd/zykc/fwzn 公开；tzgg/xngs 需 CAS | 公开源直接抓；tzgg/xngs 用教师登录 Cookie |
| 增量去重 | ✅ aid 自增唯一 | 以 `aid` 为主键，新 id 即新文 |
| 热度信号 | ❌ 无阅读量 | 放弃浏览数，改用 AI 评分 |
| RSS/API | ❌ 无 | 必须自建爬虫 |
| robots 限制 | 未实测，建议抓取前查 `/robots.txt` | 遵守，控制频率（建议 ≥10 分钟/次） |

**抓取_pipeline（对标 AIHOT）**：
1. **Scheduler**：每 10–30 分钟触发。
2. **Fetcher**：对 `{xwkd, zykc, fwzn}` 免登录拉列表；对 `{tzgg, xngs}` 带教师登录 Cookie 拉列表；可扩展 `iguopin.com` / `ncss` 作外部源。
3. **Parser**：提取 aid/标题/时间/链接；新 aid → 拉详情全文 + 图片。
4. **Dedup & Store**：PostgreSQL/SQLite 存 `articles(aid, tag, title, pub_time, source, body, img)`。
5. **AI Scorer（类 AIHOT 核心）**：调 LLM 对每条：
   - 打 **0–100 重要度/相关度分**；
   - 自动分类（宣讲会/双选会、政策申报、竞赛获奖、基层就业、校友校企、系统指南）；
   - 生成 **推荐理由**（"为什么暨南学生该看这条"）；
   - **主题聚类**：多篇同主题（如"职业规划大赛"反复出现）→ 标记为"当前热点"。
6. **Output**：时间线 + 分类页签 + 当前热点 + 搜索 + 收藏；通过 **API / Web / Coze 智能体** 暴露。

## 五、AIHOT 模式 → 本站映射表

| AIHOT 能力 | 在本站的实现 |
|---|---|
| 168 个信源 | 5 个栏目 tag（+国聘/NCSS 外部源）= 你的"信源矩阵" |
| DeepSeek 预筛 + 0–100 分 | LLM 对每条资讯打分 + 分类 + 推荐理由 |
| 干净时间线 | 按 `pub_time` 倒序 |
| 推荐理由 | "暨南学生为什么该关注"一句话 |
| 分类页签（模型/产品/…） | 宣讲会/双选会、政策申报、竞赛、基层就业、校友校企、指南 |
| 当前热点（几个源在报） | 同主题多文聚类（如职业规划大赛连发=热点） |
| 信源分级 | 官方(就业中心)>院系风采>转发(国聘/NCSS) |
| 收藏 | 学生标记"已读/想参加" |
| Web/Skill/RSS/API | 网页时间线 + Coze 智能体接入（接「暨小捞」） |

> **闭环价值**：这个热点抓取层 = 「暨小捞」的"眼睛"。智能体不再只靠静态知识库，而是**实时感知暨南就业动态**，主动给学生推"本周新出的双选会/截止申报"，正好实现前面设计的"隐藏机会雷达 + 预判式关怀"。

## 六、你作为就业办的独有能力（别人抄不走）

1. **教师登录态**：直接抓 tzgg/xngs（学生最关心的通知/公示），外部开发者做不到。
2. **找厂商要 API**：站点基于商业就业系统，可联系运维开通数据接口，免爬虫。
3. **接内部就业系统**：招聘/宣讲会/双选会原始数据在你权限内，可做最全源。
4. **公信力背书**：官方身份做聚合，学生天然信任，且合规边界清晰。

---

## 七、风险与合规红线

- ⚠️ **robots.txt & 频率**：抓取前先查 `scdc.jnu.edu.cn/robots.txt`，控制频率，避免对官网造成压力。
- ⚠️ **版权**：聚合展示需标注来源、保留原文链接，不可全文搬运牟利；校内使用通常 OK，对外发布需授权。
- ⚠️ **隐私**：tzgg/xngs/就业系统可能含学生姓名、学号、拟录用等敏感信息——聚合时**必须脱敏**，仅展示与"热点"相关的非敏感字段。
- ⚠️ **凭证安全**：教师登录 Cookie 勿硬编码进公开仓库，用环境变量/密钥管理。
- ⚠️ **数据时效**：官网改版/路径变更会导致爬虫失效，需监控告警。

## 八、MVP 落地步骤（先跑通再用）

1. **Day 1**：抓 `xwkd` 列表前 3 页 + 每篇详情，验证解析稳定；查 `robots.txt`。
2. **Day 2**：建 SQLite，`aid` 去重入库；加 `?page=N` 自动翻页。
3. **Day 3**：接 LLM 打分+分类+推荐理由+主题聚类，输出 JSON。
4. **Day 4**：做最简网页时间线（标题+时间+分类+理由+原文链接）。
5. **Day 5**：把 JSON 喂给 Coze「暨小捞」知识库/API，实现"实时热点主动推"。
6. **(进阶)**：用教师 Cookie 扩 tzgg/xngs；联系厂商要 API；接国聘/NCSS 外部源。
