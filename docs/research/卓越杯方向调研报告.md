# 「卓越杯」人工智能创新实践大赛 · 方向调研与灵感报告

> 研究对象：暨南大学管理学院企业管理系「卓越杯」AI 创新实践大赛（主题：智创未来·人人皆可 AI）
> 调研目的：结合其他高校与同类赛事的获奖方向、热点与评审逻辑，给你（管理学院学生，大概率无编程基础）提供**选赛道 + 选方向**的可落地建议。
> 关键时间：初赛截止 **2026-10-08**，今天 9-22，只剩约 **16 天** —— 所有建议都按"能快速落地"筛选。

---

## 一、先说结论：你应该选哪条路

结合你"管理学院 / 可能零代码基础 / 时间紧 / 评委是本院老师"的现实，三个赛道的性价比排序：

| 优先级 | 赛道 | 推荐做法 | 为什么适合你 |
|---|---|---|---|
| ★ 最推荐 | **B 应用实践**（低代码 Demo） | 用 Coze / 百度智能体 / Dify 做一个"暨南或商科专属"校园智能体，录屏演示 | 评审"场景落地价值"占 **40%**（权重最高）；低代码不写代码也能跑；管理学院评委对"AI+商科/校园"天然有共鸣 |
| ★ 最稳（零基础） | **A 创意探索**（无代码） | 做"AI + 百廿校庆 / 侨校文化"生成内容（短片 / 音乐 MV / 绘本） | 无需编程；原创性占 **40%**；紧扣校庆主题易出彩；可走"初赛后转 B 赛道"机制 |
| ○ 有学术兴趣 | **C 实证研究**（论文） | 做"本校学生人机协作"问卷研究 | 数据好收集（发问卷给同学）；主题与赛道五个方向完全对口 |

**一句话**：无基础就冲 A（校庆文化内容）或 B（低代码校园智能体）；想拿"真东西"进简历就做 B；有学术训练就做 C。A 报名后若做出原型，可申请转 B 决赛（章程明写"赛道转换机制"）。

## 二、其他高校 & 同类比赛的获奖方向（灵感库）

### 2.1 校园 AI 应用大赛的"真实获奖项目"（最该抄的作业）

这些是一线高校校园场景赛的获奖清单，**直接对应你要做的 B 赛道**：

### 2.2 商科 / 经管学生的差异化打法（你的最大护城河）

你是企业管理系，别和计算机系拼算法，**拼"AI + 商科场景"**：

- **贵州财经大学「墨智双擎」**（金融学学生）：自研 Drawing 多模态模型，帮**小微经营者**做品牌内容，拿下**中国国际大学生创新大赛国金 + 挑战杯特等奖**（财经类院校首个同年包揽），已服务 1000+ 小微创业者。→ 启示：**"AI 帮普通人/小商户解决问题"是商科生的黄金选题**。
- **港中深经管「零代码造 AI 智能体」**（直接对标你）：
  - **Super VOC Agent**：自动抓取用户评论→情绪标签→部门路由→结构化总结，推送到飞书（企业 VOC 流程自动化）
  - **Longlong CourseMate**：经管学院**选课助手**，整合教务/SIS/大纲多源数据，用 RAG + 多支路验证做课程推荐
  - 作者反思：低代码 ≠ 零门槛，仍需**逻辑思维 + 系统调试能力**
- **伊利诺伊大学 Gies 商学院「AI Solopreneurship」**：无编程学生 15 周用 AI 工具做出可上线 App（MoneyNova 留学理财、DormPlate 校园外卖、Tone Match AI 邮件语气）

暨南是侨校、今年 120 周年、企业管理系 101 周年 —— **AI + 华侨文化 / 校史 / 商科传承**是别人抄不走的差异化角度：

### 2.4 同类赛事的赛制与评审风向（印证你的打法）

- **vivo AIGC 创新赛**（762 高校 / 9880 人）：设"创新应用 + 内容创作"两赛道，明确说**评审已从纯技术转向"问题真实性 + 方案可运行性 + 价值表达清晰度"**。
- **UXPA 中国 2026（新增 AI 智能体赛道）**：可用 Coze/Dify/GPTs，**无强制编程门槛**，作品类型=对话智能体/可插拔 AI 技能/多智能体协同/AI 增强产品。
- **安徽「星火杯」大模型应用创新赛**（科大讯飞）：基于星辰 Agent 平台，聚焦**大学生学习/生活/就业场景**，要求"认知-决策-执行闭环"，送 88 元算力额度。

## 三、分赛道具体方向清单（可直接照抄选题）

### A 赛道 · 创意探索（无代码，原创性 40% + 场景洞察 30% + AI 运用 30%）
1. **【强烈推荐】AI + 百廿校庆 / 侨校文化内容**
   - 用可灵 / 即梦 / Suno / Midjourney 做：校庆主题短片、侨校精神音乐 MV、百年商科故事绘本、非遗+侨乡文化 AI 短片
   - 参照西京学院 13 部非遗微短剧（拿国一）、FPT Shapes of Heritage
   - 必须：附 500 字创作说明（灵感、工具步骤、人工调整点），**明确标注 AI 生成**
2. **AI 创意方案说明书（校园痛点）**：选一个具体痛点（小组作业分工 / 简历修改 / 选课分散 / 社团通知淹没），用 AI 工具设计解决方案 —— 只交说明书，竞争力弱于做出原型者，**建议同步准备转 B**。

### B 赛道 · 应用实践（低代码 Demo，技术可行 30% + 产品完整 30% + 落地价值 40%）
3. **【最推荐】暨南 / 商科专属校园智能体**（Coze / 百度智能体 / Dify）
   - "暨南商科研学助手"：经管学生文献/案例/考研/实习资讯聚合（仿 Longlong CourseMate）
   - "小微商户 AI 品牌助手"：仿贵州财大墨智双擎，帮校园周边 / 侨乡小店做内容（B 赛道落地价值高）
   - "AI 简历诊断 + 模拟面试"：春招刚需（仿云就业平台、山西工程科技职大）
4. **校庆 / 侨校文化智能体**
   - "百廿暨南 AI 讲解员"：校史问答智能体（RAG + 校史资料），仿东华招生问答 / 韩师本地通
   - "侨乡文化 AI 导览"：结合暨南侨校特色
5. **校园生活痛点智能体（最易落地）**
   - "暨南二手闲置 AI 匹配"（仿天华一等奖）、"小组作业 AI 协作助手"、"社团活动 AI 推荐"（仿东华 RAG 推荐）

### C 赛道 · 实证研究（论文，研究规范 30% + 理论创新 30% + 问题重要 40%）
6. **人机协作研究（直接对口赛道五个主题）**
   - 选题 a：**哪些变量促进/制约人与 AI 协同创新** → 问卷调研本校学生用 AI 做项目的体验，变量取"技术素养 / 信任校准 / 任务类型"（参照 HICSS 2025、经管 AI 探界反思）
   - 选题 b：**人机协作在何处受限** → 结合 LLM-HAS（自主 vs 协作范式之争）、过度自动化风险（参照 Philip S. Yu, arXiv 2506.09420）
   - 选题 c：**责任归属 / 伦理 / 权力转移** → 用 AI 做作业的学术诚信、就业指导人机协同的权力转移（参照甘肃日报 / 人民网 AI 就业指导报道）
   - 要求：研究动机 + 理论解读 + **数据收集分析**（发问卷 + 访谈即可，时间紧但可行）

## 五、拿奖的"隐藏评分点"（来自评审逻辑）

1. **B 赛道"场景落地价值"占 40%** → 选题宁可小、要真痛点，别炫技术。
2. **可交互 > PPT**：评委想看到"能输入、能处理、能输出"的 Demo（智能选课助手、简历优化器、笔记整理工具都是范例）。
3. **30 秒讲清价值**：答辩先讲具体场景痛点 → 再讲方案 → 最后给效果对比，别讲模型架构。
4. **原创 + 标注**：AI 生成内容必须明确标注；引用须注明出处（章程第七条）。
5. **跨学科组队加分**：鼓励跨专业，拉一个会点技术的同学能直接把 A 升到 B。
