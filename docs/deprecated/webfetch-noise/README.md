# deprecated · WebFetch 噪音配方归档（2026-09-23）

本目录存放 **已从 `recipes/` 移出的 11 条「WebFetch 噪音」配方**，仅作留痕，**不再进入索引**（不会被 `llms.txt` / `api/experiences.json` 收录）。

## 为什么移出

这批配方由子 Agent 用 **高层 WebFetch 工具** 抓公开页生成，复盘时发现三类硬伤，不满足入库标准：

| 问题 | 说明 |
|---|---|
| ① 真实域名泄漏 | 部分配方正文直接出现真实可识别域名（如新闻门户/社交站的 `track.*`、`s.*` 等），违反红线「配方中站点域名一律匿名化」 |
| ② `model` 不实 | 统一标注 `model: Hy3`，与实际执行者不符 |
| ③ 伪坑（不可复现） | 大量「死胡同」实为 **WebFetch 工具自身限制**（自动解码、自动转 markdown、无头不可控）伪装成「业务坑」，换用真实 HTTP 客户端（requests）后根本无法复现，属不可复现的经验 |

## 替代方案

已用 **真实 Python `requests` 脚本** 重跑采集任务，产出 12 条 **可复现** 的配方（`recipes/recipe-py-*.md`），原始提交 JSON 见 `docs/submissions/2026-09-23-phaseB/`。

## 说明

- 保留本目录是为了**可追溯**：能看到「哪些配方被否掉、为什么否掉」，而不是无声删除。
- 若后续要研究「高层抓取工具 vs 裸 HTTP 客户端的差异」，这批材料本身仍有参考价值。
